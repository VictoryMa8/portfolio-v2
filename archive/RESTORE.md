# Previous portfolio v2

`portfolio-before-redesign/` contains the original site and build files. It can be previewed by serving the repository and visiting `/archive/portfolio-before-redesign/`.

From the repository root, run `python3 archive/restore_prev.py --dry-run` to verify the archive, or `python3 archive/restore-previous-site.py` to switch back. Restoration saves the current redesign in a dated backup first. See the root README for details.
